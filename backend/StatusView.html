Essential Storage Only

Browser Storage & Cookie Transparency

How this portal uses browser storage: By default, login sessions are stored only in JavaScript memory and cleared when you close the tab. If you check "Remember me" when signing in, an opaque bearer token is saved in localStorage (pb_lms_session_token_v1). Because Google Apps Script HTML Service runs inside a sandboxed iframe, custom HttpOnly cookies cannot be issued. We never store passwords, banking details, profile records, or login bearer tokens in cookies, and we use zero advertising or tracking cookies.

    How Unavailability Email Notifications Work (Security & Reliability Architecture):
    • Authorized Sender Identity: All outbound portal emails are sent as Pattanabhumi Biology (pattanabhumi.biology@gmail.com) via Google Apps Script GmailApp / MailApp.
    • Server-Configured School Recipient Only: The recipient address is read strictly from server-side Settings.ADMIN_NOTIFICATION_EMAIL. Students cannot supply arbitrary recipient addresses or inject email headers.
    • No Gmail Password in Application: No Gmail password, SMTP password, or mail secret belongs in or is stored anywhere in this application.

Because email does not support two-phase commit with Google Sheets, the portal never promises exactly-once email delivery: if sending succeeds but recording the SENT update fails, the status is shown honestly as UNCERTAIN_POST_SEND_UPDATE_FAILED and automatic/manual resends are locked to prevent duplicate emails. Refreshing the page only reads existing records and never resends an email.
    Beginner Setup & Event Marker Guide

    How to Add Course & School-Wide Events in Google Calendar (6-Step Beginner Instructions)

    This portal never embeds a public Google Calendar <iframe>. Instead, the Google Apps Script backend reads your private school calendar and shows only events that carry an approved marker on its own line in the event description:

    1

    Step 1: Locate the Course ID in Admin

    Open Admin Dashboard (Tab 3: Courses, Sections & Cards), select the course, and copy its course UUID marker: PB_COURSE_ID: [course UUID].

    2

    Step 2: Create the Event in the Correct Calendar

    Open Google Calendar for the school's configured private Calendar ID (CALENDAR_ID) and create your class event (timed, all-day, multi-day, or recurring) in Asia/Bangkok time.

    3

    Step 3: Add the Marker

    In the event Description field, add a dedicated line with PB_COURSE_ID: [course UUID] (enrolled students only) or PB_ALL_STUDENTS (school-wide). Events without an approved marker remain hidden.

    4

    Step 4: Save as Private

    Save the event in Google Calendar and keep the calendar Private. Never make the calendar public or embed a public calendar frame.

    5

    Step 5: Open the Month in the Website

    Return to this Class Calendar view and select the target month using the month selector toolbar above.

    6

    Step 6: Test Enrolled vs. Non-Enrolled Students

    Verify with an enrolled student (student_a) that the course event is shown, and with a non-enrolled student (student_b / student_c) that only PB_ALL_STUDENTS events appear.

    Please review and acknowledge the current Pattanabhumi Biology Privacy Notice before accessing your portal.

    1. Information We Collect to Support Your Learning

    Pattanabhumi Biology collects your student profile (username, full name, and email address), course enrollments, assessment progress, tuition payment records, uploaded transfer slips, and class absence notices so we can deliver your biology courses, verify tuition payments, and keep your class schedule up to date.

    Your student records, uploaded course handouts, and payment slips are stored securely in the school’s private cloud storage and are accessible only to you and authorized school instructors and administrators.

    • Standard Sign-In: When you sign in without checking "Remember me", your session stays active only while your browser tab is open.
